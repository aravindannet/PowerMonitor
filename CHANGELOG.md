# Changelog

All notable changes to PowerMonitor are recorded here.

## [Unreleased]

## [0.1.0] - 2026-10-11

### Added
- Native SwiftUI app that reads power, load, and temperature data from macmon, with no admin password.
- Analog total-power meter, load knobs, cluster faders, and per-core LED columns.
- Power breakdown, frequency bars, temperature bars, readouts, and a 90-second history graph.
- App icon.

### Changed
- Closing the window now quits the app and stops the background sensor process.
